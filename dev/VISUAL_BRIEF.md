## 構成
試合ロジックは横画面(800x600)座標のまま、`mobile_view.py` で90度回転して縦画面(540x960)に表示する。入口 `mobile_main.py`、操作 `touch_input.py`、定数 `constants.py`。

- ビルド: `python dev/build_web.py`（pygbag, ffmpeg。`pip install -r requirements-build.txt`）
- テスト: `python dev/test_mobile.py`, `python dev/test_gameplay.py`
- 画面出力: `python dev/render_mobile.py`（`dev/out/mobile/` に PNG。必ず目で確認する）
- ヘッドレス実行: `SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy`

PC版(`main.py`)の見た目とバランスは変えない。サイズなど当たり判定に関わる値はスマホ版専用にする。

## オーナーの要望
芋虫の身体が表示されない。演出がダサく、かっこよさを感じない。小さくて見づらいので、パッと見て分かるものにしたい。芋虫の世界観に合わせる。身体は丸を並べず、丸と丸の間をシームレスにつなぎ、凹凸のないものにする。

## 1. 体節が表示されないバグ（最優先）
壁は内部で生成されるのに画面に出ない。有力な原因（未検証）: `Fence.until` は `game.game_time` 基準なのに、`mobile_main.py` の main ループは描画に `time.perf_counter() - start_time` を渡しており、`caterpillar_art.fence_fade` が寿命切れと判定している疑い。再現してから直す。実際のループと同じ時計の渡し方で「這った跡のピクセルが描かれる」ことを確かめる回帰テストを追加する。

## 2. 芋虫の身体
- 頭から尻尾まで、輪郭がなめらかな1本のチューブとして描く。節の丸、くびれ、つなぎ目の段差、節ごとの色分けを出さない。頭も胴と同じ太さ。
- 曲がり角でも凹凸が出ないようにする（線分の間を丸くつなぐか、点列をなめらかに補間する）。
- 這った跡（壁）と頭は一続きに見せる。ダッシュ中は体節が出ない仕様なので途切れてよい。壁が消えるときは尻尾側から縮むように見せる。
- 色は単色に濃い輪郭。当たり判定と見た目の太さをそろえる。

## 3. C案「絵本の庭」のデザイン
明るく、かわいい、切り絵の絵本のような世界。コート、タイトル、ボール、ゴール、スコア、ボタンをこの世界観で統一する。

- **共通:** 輪郭 `#2B2A22`（太め）。丸みのある形。文字は Mochiy Pop One（SIL OFL。`assets/fonts/` に同梱し、ライセンスを README に記す）。入手できなければ既存の ZenMaruGothic を使い、報告する。
- **タイトル:** 背景 `#FDF1C7`、右上に太陽 `#FFC93C`、下に2段の丘 `#A8D65C` / `#6DBB4A`、ピンク `#FF7E9D` の花。ロゴは「芋虫」緑 `#2E9E4F`、「ホッケー」赤 `#E8352E`。大きな緑の芋虫と大きなてんとう虫を置く。ボタンは「CPU芋虫と対戦」黄 `#FFC93C`、「2匹で対戦」`#FDF1C7` の丸いピル型。難易度の選択、遊び方、BGM の切替も同じ世界観で残す。
- **コート:** 地 `#6DBB4A`、苔の広場 `#DDEE9A` に角丸と太い輪郭、苔のまだら `#C5E27A`。中央は白の破線。コート両脇の黒い帯はなくし、画面を広く使う。
- **ゴール:** 上下の中央に花びら色のアーチ。上は `#FFC93C`、下は `#FF7E9D`。
- **芋虫:** 自分は緑 `#49BE69`、相手は紫 `#9C6CE5`。大きな白目と黒目で、進行方向を見る。
- **ボール:** てんとう虫。赤 `#E8352E`、中央の線、黒い点4つ。十分大きく。
- **スコア:** コートの隅に、持ち主の色の丸バッジで大きな数字。遠目でも読める大きさ。ポーズは右上の丸ボタン。

## 4. パッと見の分かりやすさ
芋虫とボールを今より大きくする（目安: 試合画面で身体の太さ 60px 前後、ボール直径 60px 前後）。コートとの明度差を十分取る。コートの広さに対して窮屈になりすぎないよう、シミュレーションで得点が入ることを確かめる。

## 5. 演出
世界観に合う形で、かっこよく、気持ちよくする。処理落ちと酔いを避ける。

- ゴール: 花びらと葉が舞い、大きな文字で「ゴール！」
- 勝利: 勝った芋虫がサナギになり、蝶になって飛び立つ
- ダッシュ: 身体が波打って伸びる、土ぼこりや葉の残像
- 強打: 短い画面の揺れと一瞬の停止
- 貫通: 葉のかけらが飛び散る
- ボタン: 押すと弾む
- 試合開始: カウントダウンを大きく
